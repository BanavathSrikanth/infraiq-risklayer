# InfraIQ RiskLayer

Project workspace for the InfraIQ RiskLayer platform.
apps/services/risk-service/.env
RiskLayer connects data, observed conditions, findings, risk evaluation, prioritization,
recommendations, authorized decisions, executable work, verification, residual risk,
and continued monitoring around one continuing history for each asset. AI is an
assistive proposal capability: its suggestions are always non-authoritative until
validated and explicitly approved or rejected by the appropriate domain workflow.

The canonical domain boundaries, workflow rules, service ownership, and role-specific
UX guidance are documented in
[docs/architecture/domain-and-workflow-model.md](docs/architecture/domain-and-workflow-model.md).
